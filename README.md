# Kavyanjali biotechnology portfolio

A standalone recreation of the public website at https://bio-growth-pages.lovable.app/.

## Files

- index.html contains the page structure and content.
- styles.css contains the deployed site's stylesheet.
- script.js provides the learning-stage tabs, mobile navigation, and contact-form validation.
- The four website images and favicon are stored beside the code files.

## Run

Open index.html in a browser, or serve this folder with any static web server.

The public deployment does not expose its editable Lovable project source. This package uses the public page content and deployed stylesheet, and recreates its browser-side interactions. The original contact form depends on a server action that is not included in the public files; this standalone version validates the form and opens a prefilled email draft to the published contact address.
